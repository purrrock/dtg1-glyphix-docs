# DT G1 Glyphix OS Documentation & RE Deltas (`dtg1-glyphix-docs`)

Репозиторий содержащий расширенную, переведенную и структурированную документацию по фреймворку **Glyphix OS**, а также артефакты реверс-инжиниринга прошивки смарт-часов **DT NO.1** (аппаратная платформа **Actions Semiconductor ATS3085S**, Zephyr RTOS).

Проект решает задачу перевода документации и генерации агрегированного контекста для загрузки в нейросетевые модели (LLM).

---

## 🎯 Цели проекта

1. **Синхронизация с Upstream:** Безопасное скачивание и очистка оригинальной документации из репозитория [`glyphix-os/web-docs`](https://github.com/glyphix-os/web-docs).
2. **Локализация:** Полноценный перевод документации на английский (`EN`) и русский (`RU`) языки.
3. **Фиксация фактов реверс-инжиниринга:** Ведение независимого каталога `src/re_deltas/` с фактологическими данными об аппаратных ограничениях ATS3085S, недокументированных вызовах C++ API, структуре `.pkg`-контейнеров и конфигурации VFS.
4. **Конвейер сборки контекста LLM:** Автоматическая компиляция разрозненных Markdown-файлов в 7 структурированных монолитов для каждого языка с разделителями `FILE_PATH:`.

## 🛠️ Инструкция по использованию

### 1. Безопасное обновление китайских исходников (Upstream Sync)

Скрипт `scripts/sync_upstream.py` скачивает актуальный архив с GitHub, проверяет валидность структуры, удаляет веб-мусор (`.vuepress`, `i18n`, `package.json`) и атомарно обновляет каталог `src/original_docs/`.

Запуск:
```bash
python scripts/sync_upstream.py
```

*Примечание: Если сетевое соединение прервется или архив окажется поврежден, локальные исходники в `src/original_docs/` затронуты не будут.*

### 2. Генерация файлов контекста для AI

Скрипт `scripts/build_ai_context.py` сканирует файлы из `original_docs/`, `transl/` и `re_deltas/`, расставляет системные разделители и формирует итоговые файлы в директории `ai_context/`.

Запуск:
```bash
python scripts/build_ai_context.py
```

Структура генерируемых файлов в `ai_context/<LANG>/`:
* `01_glyphix_framework_core_<LANG>.md` — Ядро фреймворка, манифесты, жизненный цикл.
* `02_glyphix_ui_components_<LANG>.md` — Компоненты UI, Flexbox, стили, анимации.
* `03_glyphix_system_api_<LANG>.md` — Модули `@system.*` и системные вызовы.
* `04_glyphix_CxxDev_<LANG>.md` — Руководство по нативной C++ разработке.
* `05_glyphix_tutorials_<LANG>.md` — Обучающие руководства и примеры.
* `06_glyphix_hardware_deltas_and_undoc_funcs_<LANG>.md` — Аппаратные лимиты ATS3085S, дамп API, отличия фактов от документации.
* `07_glyphix_toolchain_pkg_<LANG>.md` — Спецификация сборщика `gx build` и структуры `.pkg`.

## ⚠️ Правила оформления реверс-инжиниринга (`src/re_deltas/`)

Все результаты анализа бинарников прошивки, работы с дизассемблером, анализа дампов RAM/Flash и протоколов Bluetooth вносятся в папку `src/re_deltas/`. 

Данные из `src/re_deltas/` автоматически инжектируются в файл `06_glyphix_hardware_deltas_and_undoc_funcs_*.md` для **всех** языковых веток (`EN`, `RU`, `ZH`). Это гарантирует, что LLM-модель будет информирована об аппаратных ограничениях реальных часов независимо от выбранного языка общение.
