# picker

Компонент текстового селектора. Этот компонент отображает набор текста: нажатие на текстовый элемент посередине инициирует событие выбора, а прокрутка позволяет просматривать все текстовые элементы.

::: warning
Функциональность компонента `picker` не проверена и он не поддерживается.
:::

## Свойства

### `range` <decl type="string[]" set />

Все строки из значения свойства `range` будут отображаться в компоненте `picker`. Пользователь может взаимодействовать с компонентом `picker`, прокручивая или выбирая эти строки.

Способ индексации строк в значении свойства `range` см. в описании [свойства `index`](#index).

### `loop` <decl type="boolean" set />

Настраивает, будет ли компонент `picker` отображаться в цикле (то есть бесконечно). Когда это свойство имеет значение `true`, цикличное отображение включено; по умолчанию установлено значение `false`.

### `value` <decl type="string" listen />

Отслеживает текст текущего выбранного элемента. Это прослушивание срабатывает при изменении выбранного элемента в результате прокрутки. Функциональность этого свойства также может быть реализована с помощью метода `on:index="handle(rangeData[$event])"`.

### `index` <decl type="Integer" get set listen />

Индекс выбранного элемента компонента `picker`. Правило индексации следующее: индекс первой строковой позиции в массиве значения [свойства `range`](#range) равен $0$, а индексы остальных строк увеличиваются на единицу по порядку. Установка свойства `index` позволяет задать выбранный элемент компонента `picker`, а также прослушивать изменения этого свойства для отслеживания изменений выбранного элемента, вызванных прокруткой.

### `scroll` <decl type="{ x: number y: number }" get set listen />

С помощью свойства `scroll` можно отслеживать операции прокрутки, а также программно управлять отображением эффекта прокрутки в компоненте `picker`. Подобно компонентам выровненных списков, операция `scroll` для `picker` также выравнивается по ближайшему элементу.

Поскольку компонент `picker` поддерживает только вертикальный режим, поле `x` значения свойства `scroll` всегда равно `0`.

### `scrolled` <decl type="boolean" read listen />

С помощью свойства `scrolled` можно отслеживать, находится ли `picker` в состоянии прокрутки. Значение свойства, вызывающее событие, равное `true`, означает, что `picker` прокручивается в данный момент, в противном случае `picker` прекратил прокрутку.

Событие `scrolled` вызывается как операциями прокрутки, инициированными пользователем (касанием), так и программной прокруткой через свойство `scroll`. Когда `picker` останавливается после прокрутки, значение параметра события `scrolled` становится `false`.

### `damping` <decl type="number" set />

Устанавливает коэффициент затухания для анимации прокрутки `picker`. Допустимый диапазон значений составляет $[0.1, 50]$ (неподдерживаемые значения будут автоматически скорректированы до нижней или верхней границы), значение по умолчанию — $1.5$. Больший коэффициент затухания заставляет анимацию останавливаться быстрее, а значение по умолчанию создает эффект инерции на более длинные дистанции и с большей продолжительностью.

Коэффициент затухания должен быть задан как константа, его не следует изменять динамически; изменение коэффициента затухания не влияет на анимацию при возврате в исходное положение (отскоке).
