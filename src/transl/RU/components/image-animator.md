# image-animator

Компонент `image-animator` используется для воспроизведения анимации из набора кадров последовательности изображений. По умолчанию компонент является строчным элементом (inline).

<glyphix id="image-animator-1" height="190" width="360" >

```html
<div class="flex-column">
  <div class="frame-box">
    <image-animator :images="frames" :play="play" :duration="100" />
  </div>
  <div>
    <button on:click="play = 'start'">start</button>
    <button on:click="play = 'pause'">pause</button>
    <button on:click="play = 'stop'">stop</button>
  </div>
</div>
```

```js
export default {
  data: {
    play: "stop",
  },
  frames: Array.from({ length: 60 }, (_, i) => `/assets/planet-${i}.png`),
};
```

## Свойства

### `images` <decl type="string[]" set />

Задает набор кадров изображений. Каждый элемент `images` представляет собой путь или URI изображения для данного кадра. Как правило, размеры всех кадров одинаковы.

Поддерживаются изображения в формате PNG или JPEG.

Если последовательность кадров не меняется, рекомендуется объявить ее как нереактивное свойство для экономии памяти:

```js
export default {
  // frames — это нереактивное свойство компонента
  frames: [
    "/assets/sprite-1.png",
    "/assets/sprite-2.png",
    "/assets/sprite-3.png",
  ],
};
```

Преимущество такого подхода заключается в том, что несколько экземпляров компонентов будут использовать один и тот же массив `frames` (реактивные свойства копируются в каждый экземпляр компонента). Добавлять `frames` в объект `data` стоит только в том случае, если последовательность кадров действительно должна быть реактивной.

Если кадры пронумерованы по порядку, вы можете использовать следующий трюк для упрощения создания массива кадров:

```js
export default {
  // 4 кадра, пронумерованных начиная с 0
  frames: Array.from({ length: 4 }, (_, i) => `/assets/sprite-${i}.png`),
  // Или 4 кадра, пронумерованных начиная с 1
  frames: Array.from({ length: 4 }, (_, i) => `/assets/sprite-${i + 1}.png`),
};
```

Передайте массив `frames` в свойство `images` в шаблоне компонента, чтобы указать последовательность кадров и запустить анимацию:

```html
<image-animator :images="frames" play :duration="100" />
```

::: note
Свойство `images` пока не поддерживает структуру `ImageFrame` из QuickApp, поэтому вы не можете использовать определения набора кадров в виде `[{ src: '...' }, ...]`.
:::

### `duration` <decl type="number" get set />

Задает продолжительность воспроизведения каждого кадра в миллисекундах.

### `play` <decl type="'start' | 'pause' | 'stop'" get set listen />

Задает состояние воспроизведения: поддерживает старт, паузу и остановку. Изначально `image-animator` находится в состоянии `stop`, поэтому он автоматически остановится на первом кадре из [`images`](#images).

| Значение  | Описание                                      |
| :-------: | --------------------------------------------- |
| `'start'` | Начать воспроизведение с текущего кадра.      |
| `'pause'` | Поставить воспроизведение на паузу и показать текущий кадр. |
| `'stop'`  | Остановить воспроизведение и показать первый кадр. |

Как показано выше, `play` поддерживает только три значения перечисления: `'start'`, `'pause'` или `'stop'`. Тем не менее, следующий прием можно использовать для автоматического запуска анимации:

```html
<image-animator :images="frames" play :duration="100" />
```

То есть, простое написание свойства `play` без значения эквивалентно синтаксису `:play="true"` ([неявное значение свойства](/framework/component/template.md#неявные-значения-свойств)). Булево значение `true` всегда преобразуется в значение перечисления по умолчанию `'start'`. Этот подход отлично подходит для сценариев, где требуется автоматическое воспроизведение анимации последовательности кадров.

### `iteration` <decl type="number" set />

Задает количество повторов воспроизведения всех кадров в `images`. При достижении лимита повторов компонент автоматически переключится в режим `'pause'`. Значение `0` означает бесконечное воспроизведение.
