# scroll-bar

Компонент полосы прокрутки. Этот компонент отображает полосу прокрутки при наличии большого объема прокручиваемого контента, позволяя пользователю управлять прокруткой с ее помощью.

## Свойства

### `value` <decl type="number" set get listen />

Текущее значение полосы прокрутки. Это значение находится в диапазоне между `min` и `max`, значение по умолчанию — $0$.

### `min` <decl type="number" set />

Минимальное значение полосы прокрутки. Это значение не должно превышать `max`. Значение по умолчанию — $0$.

### `max` <decl type="number" set />

Максимальное значение полосы прокрутки. Это значение должно быть не меньше `min`. Значение по умолчанию — $100$.

### `pagestep` <decl type="number" set />

Шаг прокрутки полосы прокрутки, то есть расстояние прокрутки за один раз. Значение по умолчанию — $10$.
