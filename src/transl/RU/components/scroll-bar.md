# scroll-bar

Компонент полосы прокрутки. Этот компонент отображает полосу прокрутки, когда контента для прокрутки слишком много, позволяя пользователю управлять прокруткой содержимого.

## Свойства

### `value` <decl type="number" set get listen />

Текущее значение полосы прокрутки. Это значение находится в диапазоне между `min` и `max`, значение по умолчанию — $0$.

### `min` <decl type="number" set />

Минимальное значение полосы прокрутки, которое должно быть меньше или равно `max`. Значение по умолчанию — $0$.

### `max` <decl type="number" set />

Максимальное значение полосы прокрутки, которое должно быть больше или равно `min`. Значение по умолчанию — $100$.

### `pagestep` <decl type="number" set />

Шаг прокрутки полосы прокрутки, то есть расстояние прокрутки за один раз. Значение по умолчанию — $10$.
