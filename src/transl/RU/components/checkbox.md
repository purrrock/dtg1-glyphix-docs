# checkbox

Элемент `checkbox` (флажок) в активированном состоянии отображает квадрат с галочкой, что означает выбор пункта.

<glyphix id="checkbox-1" :height="65" title="Одиночный флажок">

``` html
<div>
  <checkbox id="checkbox" ::checked="checked" />
  <label target="checkbox">Check me!</label>
  <p>checked: {{ checked }}</p>
</div>
```

``` js
export default {
  data: {
    checked: true
  }
}
```
</glyphix>

::: note
`checkbox` обычно представляет собой квадрат, в котором можно поставить галочку, однако точный внешний вид зависит от устройства. В настоящее время разработчики не могут изменять цвет и другие стили `checkbox` с помощью CSS.
:::

## Свойства

### `checked` <decl type="boolean" get set listen />

Это свойство указывает, выбран ли данный флажок. Установка свойства `checked` позволяет переключать состояние флажка: когда значение равно `true`, он отображается как выбранный. Также можно управлять отдельным флажком с помощью двустороннего связывания:
``` html
<checkbox model:checked="yes" />
```

В предыдущем примере этой статьи показано использование такого связывания. Обратите внимание, что следует привязываться не к свойству [`value`](#value), а к `checked`.

Событие срабатывает только тогда, когда пользователь нажимает на флажок, что приводит к изменению свойства `checked`.

::: warning
Не устанавливайте свойство `checked` в [группе флажков](#group), чтобы избежать путаницы.
:::

### `value` <decl type="any" get set />

Значение JavaScript, определяющее значение флажка, обычно это строка или число. Это значение не отображается визуально, но может использоваться в [операциях с группами](#group).

### `group` <decl type="any[]" get set listen />

Если у вас есть несколько связанных компонентов `checkbox`, вы можете объединить свойства `group` и `value`; флажки в одной группе образуют массив выбранных значений. Пожалуйста, обратите внимание на следующий пример:

<glyphix id="checkbox-group" :height="65" title="Группа флажков" >

``` html
<div>
  <p>selected colors: {{selected.join(', ')}}</p>
  <div>
    <checkbox id="red" value="red" model:group="selected" />
    <label target="red">red</label>
    <checkbox id="blue" value="blue" model:group="selected" />
    <label target="blue">blue</label>
    <checkbox id="yellow" value="yellow" model:group="selected" />
    <label target="yellow">yellow</label>
  </div>
</div>
```

``` js
export default {
  data: {
    selected: ['yellow']
  }
}
```

``` css
label {
  margin-right: 0.5rem;
}
```

</glyphix>

Используя `model:group` или `::group` для двустороннего связывания свойства `group` с реактивным массивом (`selected` в примере), можно добиться следующего:
- После того как пользователь взаимодействует с каким-либо флажком в группе, значение реактивного массива обновляется;
- Изменения элементов реактивного массива отражаются на внешнем виде `checkbox`.

Как показано в примере выше: в начальном состоянии выбор флажков в группе определяется значением свойства `group`. В частности, для такого флажка:
``` html
<checkbox value="red" model:group="selected" />
```
Поскольку свойство `value` задает значение `"red"`, когда значение реактивного свойства `selected` содержит `"red"` (например, `["red"]`), этот флажок будет выбран. Повторный клик пользователя по этому флажку приведет к тому, что он станет невыбранным, а элемент `"red"` будет удален из массива `selected`.

::: tip
Если вы не хотите группировать флажки, вы можете использовать свойство [`checked`](#checked) для управления каждым по отдельности. Но не используйте `checked` и `group` одновременно, Glyphix не рассчитан на такой сценарий.
:::

### `indeterminate` <decl type="boolean" get set />

Свойство `indeterminate` указывает, что флажок находится в **неопределенном** состоянии. Когда это свойство имеет значение `true`, посередине флажка отображается горизонтальная линия, похожая на знак минус, обозначающая неопределенность его состояния.

Неопределенное состояние может использоваться, когда у элемента есть несколько подэлементов: если выбраны все дочерние элементы, выбирается и родительский; если не выбран ни один, родительский также не выбирается. Если выбрана лишь часть дочерних элементов, родительский элемент переходит в неопределенное состояние.

В следующем примере демонстрируется такое использование. Здесь показан список ингредиентов для зачарования стола: когда вы выбираете только часть рецептов, флажок «Enchantment table» переходит в частично выбранное состояние. Как вы можете видеть, этот пример позволяет использовать родительский флажок для выбора или отмены выбора всех дочерних элементов.

<glyphix id="checkbox-indeterminate" :height="140" title="Трехсостояниевой флажок" >

``` html
<div>
  <div>
    <!--
      Когда selected.length == 3, entirety выбирается, в противном случае:
      - Если selected.length == 0, то не выбран;
      - В остальных случаях выбрана лишь часть рецептов, поэтому состояние indeterminate. 
      -->
    <checkbox id="entirety"
              :indeterminate="selected.length && selected.length < 3"
              :checked="selected.length == 3"
              on:checked="selectEntirety" />
    <label target="entirety">
      &nbsp;Enchantment table:
    </label>
  </div>
  <div class="group">
    <div for="x in parts">
      •
      <checkbox :id="x" :value="x" model:group="selected" />
      <label :target="x">&nbsp;{{x}}</label>
    </div>
  </div>
</div>
```

``` js
export default {
  data: {
    selected: ['Diamonds'],
  },
  parts: ['Book', 'Diamonds', 'Obsidian'],
  // Вызывается при клике на флажок entirety для установки состояния выбора всех рецептов
  selectEntirety(status) {
    // Используйте [...this.parts] для копирования списка, чтобы избежать изменения исходного массива
    this.selected = status ? [...this.parts] : []
  },
}
```

``` css
.group {
  margin-left: 0.4rem;
}
```

</glyphix>

::: tip
При установке свойства `checked` (обратите внимание: именно при установке, а не при сбросе) свойство `indeterminate` автоматически очищается. Даже если у флажка установлены оба этих свойства, он будет отображаться как выбранный, а не в неопределенном состоянии.
:::

### Поведение CSS

Флажки по умолчанию являются строчными элементами (inline), их размеры определяются CSS-свойством `font-size`, и они выравниваются по базовой линии текста. Пожалуйста, не задавайте вручную свойства `width` и `height`, так как это может привести к искажению отображения.
