# progress-arc

Компонент `progress-arc` используется для отображения кругового индикатора выполнения (прогресс-бара) и по умолчанию является блочным элементом.

## Свойства

### `max` <decl type="number" set />

Максимальное значение прогресса. Значение [`value`](#value) не может быть больше него.

### `min` <decl type="number" get setet />

Минимальное значение прогресса. Значение [`value`](#value) не может быть меньше него.

### `value` <decl type="number" get set listen />

Установка значения прогресса. Отображаемая доля прогресса зависит от соотношения значения свойства `value` в диапазоне от `min` до `max`, при этом коэффициент отображения ограничивается в пределах от $0\% \text{ до } 100\%$. Значение `value` является целым числом; если задано число с плавающей точкой, будет взята только его целая часть.

### `busy` <decl type="boolean" get set />

Устанавливает, находится ли компонент `progress-arc` в состоянии занятости (загрузки). В этом состоянии отображается анимация загрузки вместо значения свойства `value`. В следующем примере показано, как использовать круговой индикатор выполнения для симуляции анимации загрузки:

<glyphix id="components-progress-arc-busy" height="100" width="300" title="Симуляция анимации загрузки">

``` html
<progress-arc busy :startAngle="0" :stopAngle="360" />
```

</glyphix>

В этом примере начальный и конечный углы индикатора выполнения отличаются на $360^\circ$. В таком случае свойство `busy` позволяет отобразить типичный эффект анимации загрузки.

::: tip
Если индикатор выполнения имеет форму кольца, всегда будет отображаться фиксированный эффект анимации загрузки, при этом начальный и конечный углы не имеют значения.
:::

### `startAngle` <decl type="number" get set />

Начальный угол дугового индикатора выполнения, значение по умолчанию — $135$. Более подробную информацию см. в разделе [Настройка углов](#настройка-углов).

### `stopAngle` <decl type="number" get set />

Конечный угол дугового индикатора выполнения, значение по умолчанию — $405$. Более подробную информацию см. в разделе [Настройка углов](#настройка-углов).

## Инструкции по использованию

### Настройка углов

В отличие от линейного компонента [`progress`](progress.md), для корректного отображения дугового или кругового индикатора выполнения необходимо правильно настроить свойства `startAngle` и `stopAngle`. Оба эти свойства используют градусы в качестве единицы измерения. В системе координат экрана $0^\circ$ указывает в горизонтальном направлении вправо (т.е. на позицию «3 часа» на циферблате часов) и увеличивается по часовой стрелке, уменьшаясь против часовой стрелки.

Отображение `progress-arc` выполняет линейную интерполяцию диапазона углов на основе пропорции `value` в диапазоне $[\texttt{min}, \texttt{max}]$. В частности, пользователь увидит, что подсветка прогресса начинается с `startAngle` и заканчивается на `valueAngle`:

$$
\begin{aligned}
  k &= \frac{\texttt{value} - \texttt{min}}{\texttt{max}-\texttt{min}}\\
  \texttt{valueAngle} &= (1-k)\texttt{startAngle} + k\cdot\texttt{stopAngle}
\end{aligned}
$$

Поэтому для отображения полного кольцевого индикатора выполнения необходимо, чтобы начальный и конечный углы отличались на $360^\circ$, даже если визуально эти углы совпадают. Кроме того, начальный угол может быть больше конечного, что инвертирует направление прогресса.

В следующем примере показаны реальные эффекты различных конфигураций углов. Обратите внимание, что второй пример демонстрирует прием обратного отображения прогресса.

## Спецификация CSS

### Расчет размеров

Отображаемый размер `progress-arc` определяется его свойствами `width` и `height`. Компонент `progress-arc` заполняет более короткую ось, а центром дугового индикатора выполнения является центр элемента. По умолчанию размер `progress-arc` может быть близок к размеру одного символа, что может привести к очень странному отображению. Поэтому обычно требуется явно указывать ширину и высоту в CSS или использовать другие разумные стратегии компоновки.

::: tip
Лучше всего задать разумную ширину и высоту для компонента `progress-arc`, иначе он может оказаться неразличимым. Как минимум, следует установить CSS-свойство `width`, и стратегия компоновки компонента автоматически применит соотношение сторон $1:1$.
:::

### Свойства CSS

Внешний вид компонента `progress-arc` можно настроить с помощью CSS.

#### `stroke-width`

Это свойство определяет ширину контура дуги компонента `progress-arc`. Тип значения — [длина](/framework/render/style-and-layout.md#长度), единицы в процентах не поддерживаются.

::: tip
Если вы хотите, чтобы толщина линии рисования компонента `progress-arc` была пропорциональна размеру шрифта, рекомендуется использовать единицы длины [`rem`](/framework/application/font-config.md#rem-字号单位), например `0.15rem`.
:::

#### `color`

Устанавливает цвет выделенной полосы прогресса `progress-arc`. По умолчанию используется цвет системной темы.

#### `background-color`

Устанавливает цвет фоновой полосы прогресса `progress-arc`. По умолчанию цвет настраивается в соответствии с системной темой.
