# slider

Ползунок (slider), по умолчанию является блочным элементом.

## Свойства

### `value` <decl type="number" get set listen />

Текущее значение, значение по умолчанию: $10$.

При установке свойства `value` изменяется текущее значение компонента. Вы можете отслеживать изменения текущего значения с помощью директивы `on`, которая будет срабатывать при каждом изменении значения.

### `min` <decl type="number" set />

Минимальное значение, значение по умолчанию: $0$.

### `max` <decl type="number" set />

Максимальное значение, значение по умолчанию: $100$.

### `vertical` <decl type="boolean" set />

Если значение свойства `vertical` равно `true`, компонент `slider` будет отображаться вертикально, в противном случае — горизонтально. Значение по умолчанию: `false`.

## Спецификация CSS

Разработчики могут настраивать внешний вид компонента `slider` с помощью CSS.

### Расчет размеров

Ширина и высота `slider` по умолчанию равны размеру шрифта элемента, который задается свойством [`font-size`](/framework/generic/styles.md#font-size) (или наследуется). Вы можете задать собственные размеры `progress` с помощью свойств [`width`](/framework/generic/styles.md#width) и [`height`](/framework/generic/styles.md#height).

### CSS-свойства

Следующие CSS-свойства могут быть весьма полезны:
- [`background-color`](/framework/generic/styles.md#background-color) управляет фоновым цветом `slider`;
- [`color`](/framework/generic/styles.md#color) управляет цветом полосы прогресса `slider`;
- [`border-radius`](/framework/generic/styles.md#border-radius) позволяет сделать углы `slider` скругленными, например, значение `50%` создаст полукруглые края.

Другие CSS-свойства также могут пригодиться, например, вы можете использовать свойство [`border`](/framework/generic/styles.md#border) для настройки стиля рамки.

### CSS Псевдоэлементы

#### `value`

Этот псевдоэлемент позволяет отдельно задавать стиль полосы прогресса `slider` без учета фоновой части. Например, можно задать разные радиусы скругления для фона полосы прокрутки и для самой полосы прогресса, чтобы внешняя рамка имела закругленные концы, а полоса прогресса — прямые.

``` css
slider {
  border-radius: 50%; /* Скругление углов фона полосы прокрутки */
}

slider::value {
  border-radius: 0; /* У полосы прогресса нет скругления углов */
}
```

#### `thumb` <experimental/>

Псевдоэлемент `thumb` используется для определения стиля ползунка `slider`. По умолчанию `slider` не содержит ручки (ползунка); чтобы она отображалась, необходимо указать ширину и высоту элемента `thumb`:
``` css
slider::thumb {
  width: 150%;
  height: 150%;
  border-radius: 50%;
}
```
Значения `width` и `height` в процентах рассчитываются относительно размеров самого элемента. Ширина и высота ползунка горизонтального `slider` рассчитываются на основе CSS-свойства `height` элемента, в то время как для вертикального `slider` размеры ручки рассчитываются на основе CSS-свойства `width`. Например, если CSS элемента выглядит так:
``` css
slider {
  width: 200px;
  height: 24px;
}
```
Тогда ширина и высота ползунка для указанного выше `slider::thumb` составят $24\rm{px} \times 150\% = 36\rm{px}$. В свою очередь, процентный радиус скругления углов ручки рассчитывается исходя из ее собственных размеров; в данном примере расчетное значение радиуса скругления псевдоэлемента `thumb` со значением `50%` составит $36\rm{px} \times 50\% = 18\rm{px}$.

Псевдоэлемент `thumb` поддерживает CSS-свойство `border`, однако граница не будет выходить за пределы размеров самого псевдоэлемента `thumb`.

### Пример CSS

В следующем примере показаны некоторые способы настройки внешнего вида полосы прогресса с помощью CSS.
<glyphix id="components-slider-styles" height="180" width="480" title="Стили Slider">

``` html
<div>
  <!-- Стиль по умолчанию -->
  <slider ::value="value" />
  <!-- Стиль полосы прогресса с прямыми краями -->
  <slider class="flat" ::value="value" />
  <slider class="more-style" ::value="value" />
  <p>value: {{value}}</p>
</div>
```

``` css
div > * {
  margin: 8px;
  padding: 6px;
}

.flat::value {
  /* Установка радиуса скругления псевдоэлемента value в 0 создает эффект прямых краев полосы прогресса */
  border-radius: 0;
}

.more-style {
  /* Пользовательский радиус скругления */
  border-radius: 30%;
  /* Цвет фона slider */
  background-color: #b3c5d7;
  /* Цвет переднего плана (прогресса) slider */
  color: #b5179e;
  /* Свойство padding позволяет настраивать отступы переднего плана slider */
  padding: 6px;
  height: 1rem;
}

/* Определение стиля ползунка прокрутки */
.more-style::thumb {
  width: 300%; /* Капсулообразный ползунок с соотношением сторон 2:1 */
  height: 150%;
  background-color: white;
  border: 4px solid #f3722c; /* Граница ползунка */
  border-radius: 50%;
}
```

``` js
export default {
  data: { value: 50 }
}
```
