# slider

Ползунок (slider), по умолчанию является блочным элементом.

## Свойства

### `value` <decl type="number" get set listen />

Текущее значение, значение по умолчанию: $10$.

При установке свойства `value` изменяется текущее значение компонента. Вы можете отслеживать изменения текущего значения с помощью директивы `on`, которая срабатывает при каждом изменении значения.

### `min` <decl type="number" set />

Минимальное значение, значение по умолчанию: $0$.

### `max` <decl type="number" set />

Максимальное значение, значение по умолчанию: $100$.

### `vertical` <decl type="boolean" set />

Если значение свойства `vertical` равно `true`, компонент `slider` отображается вертикально, в противном случае — горизонтально. Значение по умолчанию: `false`.

## Спецификация CSS

Разработчики могут настраивать внешний вид компонента `slider` с помощью CSS.

### Расчет размеров

Ширина и высота `slider` по умолчанию равны размеру шрифта элемента, который задается свойством [`font-size`](/framework/generic/styles.md#font-size) (или может наследоваться). Вы можете задать размеры `progress` самостоятельно с помощью свойств [`width`](/framework/generic/styles.md#width) и [`height`](/framework/generic/styles.md#height).

### CSS-свойства

Следующие CSS-свойства могут быть особенно полезны:
- [`background-color`](/framework/generic/styles.md#background-color) управляет цветом фона `slider`;
- [`color`](/framework/generic/styles.md#color) управляет цветом индикатора выполнения (прогресс-бара) `slider`;
- [`border-radius`](/framework/generic/styles.md#border-radius) позволяет сделать углы `slider` скругленными, например, значение `50%` создаст полукруглые края.

Другие CSS-свойства также могут быть полезны, например, для задания стиля рамки можно использовать свойство [`border`](/framework/generic/styles.md#border).

### Псевдоэлементы CSS

#### `value`

Этот псевдоэлемент позволяет отдельно задавать стили для полосы прогресса `slider`, исключая фоновую часть. Например, можно задать разные радиусы скругления для фона полосы прокрутки и для части индикатора выполнения, чтобы получить эффект, при котором внешняя рамка имеет скругленные концы, а полоса прогресса — прямые.

``` css
slider {
  border-radius: 50%; /* Скругление фона полосы прокрутки */
}

slider::value {
  border-radius: 0; /* Индикатор прогресса без скругления */
}
```

#### `thumb` <experimental/>

Псевдоэлемент `thumb` используется для задания стилей ползунка (бегунка) `slider`. По умолчанию `slider` не содержит бегунка; чтобы он отображался, необходимо явно указать ширину и высоту элемента `thumb`:
``` css
slider::thumb {
  width: 150%;
  height: 150%;
  border-radius: 50%;
}
```
Значения `width` и `height` в процентах рассчитываются относительно размеров самого элемента. Ширина и высота бегунка для горизонтального `slider` рассчитываются в процентах от CSS-свойства `height` элемента, а для вертикального `slider` — в процентах от CSS-свойства `width`. Например, если CSS элемента выглядит так:
``` css
slider {
  width: 200px;
  height: 24px;
}
```
То в этом случае ширина и высота бегунка для `slider::thumb` составят $24\rm{px} \times 150\% = 36\rm{px}$. Процентный радиус скругления бегунка рассчитывается на основе его собственных размеров. В данном примере расчетное значение радиуса скругления псевдоэлемента `thumb` со значением `50%` составит $36\rm{px} \times 50\% = 18\rm{px}$.

Псевдоэлемент `thumb` поддерживает CSS-свойство `border`, однако граница не будет выходить за пределы размеров самого псевдоэлемента `thumb`.

### Пример CSS

В следующем примере показаны некоторые способы настройки внешнего вида индикатора выполнения с помощью CSS.
<glyphix id="components-slider-styles" height="180" width="480" title="Стили Slider">

``` html
<div>
  <!-- Стандартный стиль -->
  <slider ::value="value" />
  <!-- Стиль с прямыми краями прогресс-бара -->
  <slider class="flat" ::value="value" />
  <slider class="more-style" ::value="value" />
  <p>value: {{value}}</p>
</div>
```

``` css
div > * {
  margin: 8px;
  padding: 6px;
}

.flat::value {
  /* Установка радиуса скругления псевдоэлемента value в 0 дает прямые края прогресс-бара */
  border-radius: 0;
}

.more-style {
  /* Пользовательский радиус скругления */
  border-radius: 30%;
  /* Цвет фона slider */
  background-color: #b3c5d7;
  /* Цвет переднего плана (прогресса) slider */
  color: #b5179e;
  /* padding позволяет настроить отступы для переднего плана slider */
  padding: 6px;
  height: 1rem;
}

/* Определение стиля бегунка полосы прокрутки */
.more-style::thumb {
  width: 300%; /* Капсулевидный бегунок с соотношением сторон 2:1 */
  height: 150%;
  background-color: white;
  border: 4px solid #f3722c; /* Граница бегунка */
  border-radius: 50%;
}
```

``` js
export default {
  data: { value: 50 }
}
```
