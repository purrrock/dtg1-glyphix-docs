# qrcode

Компонент `qrcode` используется для отображения [QR-кода](https://en.wikipedia.org/wiki/QR_code). Этот компонент может отображать любые текстовые данные и подходит для показа URL-адресов, платежных кодов, ссылок для входа через сканирование и другой информации.

В потоковой компоновке (flow layout) компонент `qrcode` по умолчанию является блочным элементом (`block`) и занимает отдельную строку.

## Свойства

### `value` <decl type="string" get set />

Задает текстовые данные, которые необходимо отобразить в виде QR-кода. Компонент `qrcode` автоматически выбирает подходящую версию в зависимости от объема данных. В настоящее время поддерживаются версии до $12$ включительно.

## Описание CSS

Чтобы QR-код легко сканировался, следует правильно настроить CSS-свойства компонента `qrcode`, к которым относятся:
- `color`: цвет элементов (модулей) QR-кода, обычно устанавливается черным (`black` или `#000`);
- `background-color`: цвет фона QR-кода, обычно должен быть белым (`white` или `#fff`);
- `padding` / `margin`: достаточные внутренние и внешние отступы позволяют избежать слияния QR-кода с другими элементами и повышают процент успешного сканирования и распознавания;
- `width` / `height``: размеры QR-кода должны быть достаточно большими для удобства съемки камерой.

По умолчанию каждый модуль компонента QR-кода занимает область $4\rm{px}\times 4\rm{px}$, что на часах может оказаться лишь минимально распознаваемым размером. Однако такие стратегии компоновки, как flex, могут уменьшить размер QR-кода, поэтому разработчикам рекомендуется вручную задавать свойства `width` / `height` компонента QR-кода в соответствии с потребностями и проводить тестирование на устройстве.

В следующем примере показано использование компонента QR-кода. Обратите внимание, что в CSS для компонента `qrcode` заданы различные отступы — все это делается для обеспечения достаточного промежутка между QR-кодом и другими элементами интерфейса во избежание помех при сканировании.

<glyphix id="qrcode-1" :height="450" :width="350">

``` html
<div>
  <qrcode :value="text"/>
  <p>{{ text }}</p>
</div>
```

``` js
export default {
  data: {
    text: 'https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array'
  }
}
```

``` css
div {
  background-color: black;
  padding: 8px;
}

qrcode {
  margin: 16px;
  padding: 16px;
  color: black; /* Установка цвета переднего плана QR-кода в черный */
  background-color: white; /* Установка цвета фона QR-кода в белый */
  border-radius: 16px;
}

p {
  color: white;
  font-size: 0.75rem;
}
```

</glyphix>

::: tip
Всегда следует явно задавать **высококонтрастные** стили цвета модулей (`color`) и фона (`background-color`) для компонента QR-кода. Это поможет избежать снижения читаемости из-за отклонений в теме оформления по умолчанию или унаследованных стилях устройства.

Кроме того, устанавливайте достаточно большие внутренние отступы (`padding`), чтобы обеспечить простоту сканирования и распознавания.
:::
