# qrcode

Компонент `qrcode` используется для отображения [QR-кодов](https://en.wikipedia.org/wiki/QR_code). Этот компонент может отображать любые текстовые данные и отлично подходит для показа URL-адресов, платежных кодов, ссылок для авторизации по QR-коду и другой информации.

В потоковой разметке (flow layout) компонент `qrcode` по умолчанию является блочным элементом (`block`) и занимает отдельную строку.

## Свойства

### `value` <decl type="string" get set />

Устанавливает текстовые данные, которые будут отображаться в виде QR-кода. Компонент `qrcode` автоматически выбирает подходящую версию в зависимости от длины данных. В настоящее время максимальная поддерживаемая версия — $12$.

## Стили CSS

Чтобы QR-код легко сканировался, необходимо правильно настроить CSS-свойства компонента `qrcode`, включая:
- `color`: цвет точек (модулей) QR-кода, обычно устанавливается черным (`black` или `#000`);
- `background-color`: цвет фона QR-кода, обычно должен быть белым (`white` или `#fff`);
- `padding` / `margin`: достаточные внутренние и внешние отступы предотвращают слияние QR-кода с другими элементами и повышают процент успешного распознавания при сканировании;
- `width` / `height`: размеры QR-кода должны быть достаточно большими для удобства съемки.

По умолчанию каждый модуль (точка) компонента QR-кода занимает область $4\rm{px}\times 4\rm{px}$, что на часах может оказаться минимально допустимым для распознавания размером. Однако стратегии верстки, такие как flex, могут уменьшить размер QR-кода, поэтому разработчикам рекомендуется вручную настраивать свойства `width` / `height` компонента QR-кода в соответствии с потребностями и тестировать его на устройстве.

В следующем примере показано использование компонента QR-кода. Обратите внимание, что в CSS для компонента `qrcode` заданы различные отступы — все это сделано для того, чтобы обеспечить достаточный зазор между QR-кодом и другими элементами интерфейса во избежание помех при сканировании.

<glyphix id="qrcode-1" :height="450" :width="350">

``` html
<div>
  <qrcode :value="text"/>
  <p>{{ text }}</p>
</div>
```

``` js
export default {
  data: {
    text: 'https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array'
  }
}
```

``` css
div {
  background-color: black;
  padding: 8px;
}

qrcode {
  margin: 16px;
  padding: 16px;
  color: black; /* Установка цвета переднего плана QR-кода в черный */
  background-color: white; /* Установка цвета фона QR-кода в белый */
  border-radius: 16px;
}

p {
  color: white;
  font-size: 0.75rem;
}
```

</glyphix>

::: tip
Всегда явно задавайте цвета точек (`color`) и фона (`background-color`) компонента QR-кода с **высоким контрастом**, чтобы избежать снижения читаемости из-за отклонений в теме оформления по умолчанию или наследуемых стилях устройства.

Кроме того, устанавливайте достаточно большие внутренние отступы (`padding`), чтобы обеспечить легкость сканирования и распознавания.
:::
