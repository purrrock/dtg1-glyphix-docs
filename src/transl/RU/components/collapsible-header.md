# collapsible-header

Компонент `collapsible-header` используется для добавления сворачиваемой панели заголовка в прокручиваемый список. Такой эффект применяется на устройствах типа «умные часы» для экономии экранного пространства и улучшения пользовательского опыта.

::: warning
<experimental /> Это экспериментальный компонент. Не используйте его методами, не описанными в данной документации.
:::

## Свойства

Данный компонент поддерживает [общие свойства](/framework/generic/properties.md) и не имеет собственных специализированных свойств.

## Использование

Компонент `collapsible-header` должен содержать ровно два дочерних компонента, в противном случае возможно возникновение непредвиденных эффектов. Конкретный пример использования:

```html
<collapsible-header>
  <p>Это сворачиваемый заголовок</p>
  <scroll> ... </scroll>
</collapsible-header>
```

Здесь первый дочерний элемент является сворачиваемым заголовком, а второй элемент обязательно должен быть прокручиваемым контейнером, таким как [`scroll`](/components/scroll.md). Ниже приведен конкретный пример:

<glyphix id="components-collapsible-header-1" height="360" width="360" title="Сворачиваемая панель заголовка">

```html
<collapsible-header>
  <p class="title-bar" on:click="clickTitle">TITLE BAR</p>
  <scroll scroll-snap="center" deformation="fisheye">
    <p for="x in 20" class="item">item {{ x + 1 }}</p>
  </scroll>
</collapsible-header>
```

```js
import prompt from "@system.prompt";

export default {
  clickTitle() {
    prompt.showToast({ message: "title clicked" });
  }
}
```

```css
.title-bar {
  margin: 56px auto auto;
  transparent: true;
  font-size: 1.5rem;
}

.item {
  height: 33.3%;
  background-color: #ddd;
  border-radius: 20%;
  margin: 8px;
  transparent: true;
  padding: 12px;
  text-align: center;
}
```

</glyphix>

### Описание принципа работы

`collapsible-header` принимает два дочерних компонента: первый представляет собой сворачиваемую панель заголовка, а второй обязательно должен быть прокручиваемым компонентом, похожим на `scroll`. `collapsible-header` объединяет эти два компонента и управляет эффектом отображения панели заголовка при прокрутке списка.

Для управления положением панели заголовка можно использовать методы, подобные потоковой компоновке (flow layout), например:

```css
/* Верхний отступ элемента 48px, центрирование по горизонтали, подходит для круглых экранов. */
margin: 48px auto auto;
/* Отступы слева и сверху 12px, подходит для квадратных экранов. */
margin: 12px auto auto 12px;
```

Установив указанные выше стили для элемента заголовка в соответствии с вашими реальными потребностями, вы можете добиться определенного эффекта выравнивания. В качестве заголовка также можно использовать сложный компонент, содержащий дочерние элементы (например, компонент, включающий кнопку «Назад» и текст заголовка страницы). Однако обратите внимание, что при клике на панель заголовка событие клика может одновременно отправляться и в прокручиваемый список, и в панель заголовка. Если возникает конфликт, его можно решить путем предотвращения всплытия событий (stopPropagation).

### Меры предосторожности

Необходимо предоставить для `collapsible-header` ровно два дочерних компонента в соответствии с требованиями, описанными выше, и не перепутать их порядок. Кроме того, поскольку сворачиваемая панель заголовка и лежащий в основе прокручиваемый список отображаются с наложением друг на друга, это может привести к тому, что первый элемент списка будет перекрываться с заголовком. При необходимости разработчикам следует предусмотреть какой-либо способ заполнителя (placeholder), чтобы избежать наложения. Кроме того, центрированный [режим привязки](/components/scroll.md#scrollsnap) (`scroll-snap="center"`) компонента `scroll` также помогает избежать наложения.
