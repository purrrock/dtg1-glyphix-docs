# label

Компонент `label` используется для отображения текста или информации о метках и по умолчанию является строчным элементом (inline). `label` может использоваться в сочетании со следующими компонентами формы для отображения информации о метках:
- [input](input)
- [radio](radio)
- [switch](switch)
- [checkbox](checkbox)

Когда `label` связан с поддерживаемым компонентом формы, нажатие на компонент `label` также инициирует обновление значения компонента формы.

## Свойства

### `text` <decl type="string" set get />

Текстовое содержимое метки, поддерживает синтаксис атрибутов или синтаксис текстовых дочерних элементов:
``` html
<label text="label text"></label>
<label>label text</label>
```

### `target` <decl type="string" set get />

Идентификатор (ID) целевого компонента. Например:
```html
<radio id="red" /><label target="red">red</label>
```
Нажатие на компонент `label` в примере также приведет к обновлению компонента `radio` с ID `red`, однако нажатие на компонент `label` не вызовет события касания (например, `click`) целевого компонента.

Из соображений производительности поддерживаются только целевые компоненты, находящиеся на том же уровне, что и компонент `label` (то есть имеющие общего родительского компонента).

::: warning
В настоящее время изменение целевого компонента не поддерживается.
:::
