# input

По умолчанию является строчным элементом, предоставляет интерактивный интерфейс и принимает пользовательский ввод.

## Свойства

### `type` <decl type="'checkbox' | 'radio'" set />

Элемент управления, для которого можно установить указанные типы значений. Фактический вид компонента `input` определяется в зависимости от заданного типа.

### `name` <decl type="string" set />

Задает имя компонента `input`.

### `checked` <decl type="boolean" set />

Текущее состояние checked компонента, может вызывать псевдокласс checked. Работает, когда `type` равен `checkbox`. Если установлено значение `on`, `checkbox` по умолчанию отмечается галочкой.

### `value` <decl type="string" set />

Задает значение компонента `input`.
