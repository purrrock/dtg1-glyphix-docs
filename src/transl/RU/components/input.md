# input

По умолчанию является строчным элементом, предоставляет интерактивный интерфейс и принимает пользовательский ввод.

## Свойства

### `type` <decl type="'checkbox' | 'radio'" set />

Элемент управления, для которого можно задать указанные типы. В зависимости от выбранного типа определяется конечная визуальная форма компонента `input`.

### `name` <decl type="string" set />

Задает имя компонента `input`.

### `checked` <decl type="boolean" set />

Текущее состояние `checked` компонента, которое может активировать псевдокласс checked. Применяется, когда type равен checkbox. Если установлено значение `on`, checkbox по умолчанию отмечается галочкой.

### `value` <decl type="string" set />

Задает значение компонента `input`.
