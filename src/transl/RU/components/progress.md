# progress

Компонент `progress` используется для отображения полосы прогресса и по умолчанию является блочным элементом.

## Свойства

### `max` <decl type="number" set />

Максимальное значение прогресса, свойство [`value`](#value) не может быть больше него.

### `min` <decl type="number" set />

Минимальное значение прогресса, свойство [`value`](#value) не может быть меньше него.

### `value` <decl type="number" set get listen />

Установка значения прогресса. Отображаемое соотношение прогресса зависит от доли свойства `value` в диапазоне от `min` до `max`, при этом соотношение отображения ограничивается в пределах от $0\% \text{ до } 100\%$ . Значение `value` является целым числом; если задано число с плавающей точкой, будет взята только его целая часть.

### `vertical` <decl type="boolean" set />

Если значение свойства `vertical` равно `true`, компонент `progress` будет отображаться вертикально, в противном случае — горизонтально. Значение по умолчанию — `false`. 

## Спецификация CSS

Разработчики могут настраивать внешний вид компонента `progress` с помощью CSS.

### Расчет размеров

Ширина и высота `progress` по умолчанию равны размеру шрифта элемента, который задается свойством [`font-size`](/framework/generic/styles.md#font-size) (или может наследоваться). Размеры `progress` можно настроить с помощью свойств [`width`](/framework/generic/styles.md#width) и [`height`](/framework/generic/styles.md#height).

### CSS-свойства

Следующие CSS-свойства могут быть весьма полезны:
- [`background-color`](/framework/generic/styles.md#background-color) управляет цветом фона `progress`;
- [`color`](/framework/generic/styles.md#color) управляет цветом полосы прогресса `progress`;
- [`border-radius`](/framework/generic/styles.md#border-radius) позволяет сделать границы `progress` скругленными, например, значение `50%` создаст полукруглые края;

Другие CSS-свойства также могут быть полезны, например, для настройки стилей рамок можно использовать свойство [`border`](/framework/generic/styles.md#border).

### Псевдоэлементы CSS

#### `value`

Этот псевдоэлемент позволяет отдельно задавать стили для самой полосы прогресса `progress`, исключая фоновую часть. Например, можно раздельно настроить радиус скругления углов для фона шкалы и для самой полосы прогресса, чтобы получить эффект, при котором внешний контур имеет закругленные концы, а полоса прогресса — прямые.

``` css
progress {
  border-radius: 50%; /* Скругление углов фона шкалы */
}

progress::value {
  border-radius: 0; /* Без скругления углов у полосы прогресса */
}
```

### Пример CSS

В следующем примере показаны некоторые способы настройки внешнего вида полосы прогресса с помощью CSS.

<glyphix id="components-progress-styles" height="140" width="480" title="Стили полосы прогресса">

``` html
<div>
  <!-- Стиль по умолчанию -->
  <progress :value="40" />
  <!-- Стиль полосы прогресса с прямыми краями -->
  <progress class="flat" :value="50" />
  <progress class="more-style" :value="60" />
</div>
```

``` css
div > * {
  margin: 8px;
}

.flat::value {
  /* Установка радиуса скругления псевдоэлемента value в 0 создает эффект прямых краев прогресса */
  border-radius: 0;
}

.more-style {
  /* Пользовательский радиус скругления */
  border-radius: 30%;
  /* Цвет фона полосы прогресса */
  background-color: #b3c5d7;
  /* Цвет переднего плана полосы прогресса */
  color: #b5179e;
  /* Свойство padding позволяет настраивать отступы переднего плана прогресса */
  padding: 6px;
  height: 1.25rem;
}
```
