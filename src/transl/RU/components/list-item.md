# list-item

Дочерний компонент `list`, используемый для отображения конкретных элементов списка. Поддерживает вложенные дочерние компоненты и верстку, но не поддерживает прокрутку.

::: tip
Glyphix не предоставляет компонент контейнера списка, аналогичный Быстрым приложениям (Quick App), а использует [`scroll`](scroll.md) для реализации контейнера прокрутки. Аналогично, нет необходимости использовать компонент `list-item`, пожалуйста, используйте [`div`](div.md) или любые другие компоненты непосредственно в качестве элементов списка.
:::
