# list-item

Дочерний компонент `list`, используемый для отображения конкретных элементов списка. Он поддерживает дочерние компоненты и верстку, но не поддерживает прокрутку.

::: tip
Glyphix не предоставляет компонент контейнера `list`, аналогичный Quick App, а вместо этого использует [`scroll`](scroll.md) для реализации контейнера прокрутки. Аналогично, нет необходимости использовать компонент `list-item`, пожалуйста, используйте [`div`](div.md) или любой другой компонент непосредственно в качестве элементов списка.
:::
