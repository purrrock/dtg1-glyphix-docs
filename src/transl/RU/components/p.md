# p

Текстовый компонент. По умолчанию `p` является блочным элементом. В отличие от [`span`](span), компонент `p` не поддерживает перенос текста на другую строку даже при установке в качестве строчного элемента. Если требуется верстка богатого текста (rich text), следует рассмотреть использование таких компонентов, как `span`.

## Свойства

### `text` <decl type="string" get set/>

Установка текстового содержимого. Поддерживает два следующих варианта написания:

``` html
<p text="Hello Glyphix"></p>
<p>Hello Glyphix</p>
```

### `color` <decl type="string" get set/>

Установка цвета текста. Поддерживаются только шестнадцатеричные коды цветов, такие как `#f00`, `#e8bb80ff` и т. д. Это свойство является быстрым способом изменения встроенного CSS-свойства [`color`](/framework/generic/styles.md#color).

### `lines` <decl type="number" get set/>

Установка максимального количества строк текста. Текст, превышающий это число строк, будет обрезаться или сокращаться. Это свойство является быстрым способом изменения встроенного CSS-свойства [`max-lines`](/framework/generic/styles.md#max-lines).

### `text-align` <decl type="string" set/>

Установка выравнивания текста. Поддерживает такие значения, как `left`, `center`, `right` и др. Это свойство является быстрым способом изменения встроенного CSS-свойства [`text-align`](/framework/generic/styles.md#text-align).

### `font-size` <decl type="string" set/>

Установка размера шрифта текста. Поддерживает значения размеров шрифта CSS, такие как `12px`, `1.5em` и т. д. Это свойство является быстрым способом изменения встроенного CSS-свойства [`font-size`](/framework/generic/styles.md#font-size).

### `font-weight` <decl type="number" set/>

Установка жирности шрифта текста. В настоящее время поддерживаются только целочисленные значения, такие как `400`, `600` и т. д. Это свойство является быстрым способом изменения встроенного CSS-свойства [`font-weight`](/framework/generic/styles.md#font-weight).

## Советы по использованию

### Управление размером

Как правило, не следует вручную устанавливать высоту компонента `p`, например:
``` css
p.my-paragraph {
  height: 48px;
  font-size: 32px;
}
```
На первый взгляд это задает для компонента `p` высоту, превышающую размер шрифта, но на практике:
- Для однострочного текста фактическая высота некоторых шрифтов может превышать размер шрифта, и даже при высоте в `48px` может происходить вертикальная обрезка.
- Для многострочного текста установка фиксированной высоты приведет к тому, что текст будет обрезан и не отобразится полностью.

Если вы хотите контролировать количество отображаемых строк текста, вам следует использовать [`max-lines`](/framework/generic/styles.md#max-lines) и [`text-overflow`](/framework/generic/styles.md#text-overflow) для обрезки и сокращения текста, вместо установки фиксированной высоты.

### Анимация обрезки текста <version-badge since="0.9"/>

Вы можете использовать свойство [`width`](/framework/generic/styles.md#width) в сочетании с модификатором [`transition`](/framework/component/prop-modifier.md#transition-修饰符) для реализации анимации обрезки текста. Например:

``` html
<p :width="state ? 240 : 0"
   width.transition="{duration: 2.0}">
  Hello Glyphix!
</p>
```

В сочетании со стилем `max-lines: 1` это позволяет реализовать анимацию обрезки текста слева направо. Однако у этой анимации есть проблема: когда ширины недостаточно, последний символ отбрасывается напрямую, а не обрезается. Текущий обходной путь заключается в том, чтобы поместить текстовое содержимое в дочерний компонент и настроить анимацию ширины для родительского компонента:

``` html
<div :width="state ? 240 : 1"
     width.transition="{duration: 2.0}">
  <p style="max-lines: 1">Hello Glyphix!</p>
</div>
```

``` js

  data: {
    state: false

  onReady() {
    setInterval(() => this.state = !this.state, 2500)

}
```

```css
.container {
  display: flex;
  flex-direction: column;
  align-items: center;
  justify-content: center;
  font-size: 1.25rem;
}

.animated-text {
  margin: 4px;
  border: 1px solid #f00;
}

p {
  max-lines: 1;
  text-overflow: clip;
}
````

Однако при использовании элемента `div` в качестве родительского компонента у анимации возникает проблема: когда ширина равна `0`, размеры макета вычисляются как `(width: 0, height: 0)`, из-за чего элемент не может занимать вертикальное пространство, и в начале анимации происходит вертикальный скачок. Решение состоит в том, чтобы установить ширину в очень маленькое значение (например, `1px`) вместо `0`, чтобы элемент мог занимать вертикальное пространство, тем самым избегая проблемы со скачками.
