# a

Компонент якоря, по умолчанию является строчным элементом, используется для перехода на указанную страницу.

## Свойства

### `href` <decl type="string" get set />

Указывает [название страницы](/framework/application/manifest.md#pages) или строку URI, на которую необходимо выполнить переход.

``` html
<a href="page1">Перейти на страницу page1</a>
``` 

В отличие от тега `<a>` в веб-разработке, компонент `a` поддерживает только переходы между страницами и не поддерживает гиперссылки.

Свойство `href` также поддерживает строки [URI](/framework/application/resource.md#uri) вида `PageName?key=value`, то есть URI, состоящий из названия страницы (в качестве поля path) и поля query. Поле query этого URI будет преобразовано в параметры перехода на страницу. Например, при нажатии на этот элемент `<a>`:

``` html
<a href="page1?text=test-text&message=hello">Перейти на страницу page1</a>
```

Это эквивалентно вызову следующего метода [`router.push()`](/api/system-router.md#push):

``` js
router.push({
  uri: 'page1',
  params: {text: 'test-text', message: 'hello'}
})
```

::: tip
Обратите внимание, что значение поля query в URI всегда преобразуется в тип string. Таким образом, значение `100` в `page1?size=100` будет интерпретировано как строка `'100'`, а не как число `100`. Если вам нужно передать параметры определенного типа, используйте API [`router`](/api/system-router.md).
:::
