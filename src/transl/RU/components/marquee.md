# marquee

Компонент `marquee` используется для отображения бегущей строки с текстом и поддерживает вывод только в одну строку. Компонент `marquee` не поддерживает никакие дочерние компоненты, включая `span`.

`marquee` поддерживает общие CSS-свойства, однако по техническим причинам в настоящее время свойство `text-align` может не поддерживаться. Поскольку `marquee` отображает только одну строку текста и прокручивает её при превышении доступной ширины, такие свойства, как `max-lines`, также не работают.

## Свойства

### `text` <decl type="string" get set/>

Устанавливает текстовое содержимое. Используется аналогично свойству [`text`](p.md#text) компонента `p`. Когда длина текста превышает ширину `marquee`, текст начинает автоматически прокручиваться.
