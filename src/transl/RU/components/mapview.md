# mapview

Картографический компонент, используемый для загрузки и отображения карт на основе тайлов (Tile). `mapview` поддерживает панорамирование жестами, переключение уровней масштабирования, отображение текущего местоположения и прорисовку навигационных маршрутов. Это ключевой компонент для создания картографических приложений.

По умолчанию `mapview` является блочным элементом.

::: tip
`mapview` — это компонент расширения среды выполнения (runtime). Перед использованием убедитесь, что целевая платформа интегрировала модуль `mapview`.
:::

## Свойства

### `baseUri` <decl type="string" get set />

URI **базового пути** к ресурсам тайловой карты. Файлы тайлов будут храниться в этом каталоге в виде фиксированной иерархической структуры. `mapview` автоматически рассчитывает путь к нужному файлу тайла на основе текущего уровня масштабирования и координат в следующем формате:

```
{baseUri}/{zoomLevel}/{tileX}/{tileY}/normal.png     (стандартная карта)
{baseUri}/{zoomLevel}/{tileX}/{tileY}/satellite.png  (спутниковая карта)
```

Типичное использование заключается в кэшировании тайлов карты в локальном хранилище устройства с последующим указанием `baseUri` на соответствующий каталог:

```html
<mapview baseUri="internal://files/tiles/map_provider" />
```

### `tileType` <decl type="number" get set />

Тип слоя тайловой карты, возможные значения:

| Значение | Описание |
| :-: | :-- |
| `0` | Стандартная карта (по умолчанию), загружает файлы тайлов `normal.png` |
| `1` | Спутниковая карта, загружает файлы тайлов `satellite.png` |

### `loadPlace` <decl type="string" get set />

URI **изображения-заглушки**, отображаемого во время загрузки тайла. Если соответствующий файл тайла еще не кэширован локально, `mapview` отобразит это изображение в позиции тайла до тех пор, пока тайл не будет загружен, после чего вызывается обновление [`reload()`](#reload).

```html
<mapview loadPlace="/assets/imgs/loading.png" />
```

### `zoomLevel` <decl type="number" get set />

Уровень масштабирования карты, диапазон значений составляет $[3, 23]$, значение по умолчанию — $17$. Чем выше уровень, тем подробнее карта; чем ниже уровень, тем больше видимая область.

::: info
Это свойство соответствует стандарту уровней масштабирования (Zoom Level) для тайлов карт и совпадает с определениями уровней в таких популярных тайловых сервисах, как Bing Maps и Google Maps.
:::

### `arrowIcon` <decl type="string" get set />

URI изображения значка текущего местоположения. Этот значок отображается на экране в точке с географическими координатами, заданными свойствами [`navCoordinate`](#navcoordinate) или методом [`setLocation()`](#setlocation). Значок выравнивается по центру относительно координатной точки.

```html
<mapview arrowIcon="/assets/imgs/location.png" />
```

### `navCoordinate` <decl type="{ x: number, y: number }" get set />

Координаты текущего местоположения в формате `{ x: latitude, y: longitude }`, где `x` — широта (latitude), а `y` — долгота (longitude). Установка этого свойства обновляет только положение значка и не приводит к автоматическому смещению центра карты в эту координату. Если вам нужно одновременно с этим центрировать карту на текущем месте, используйте метод [`setLocation()`](#setlocation) с параметром `force: true`.

::: tip
Для сценариев, требующих отслеживания текущего местоположения в реальном времени, рекомендуется использовать метод [`setLocation()`](#setlocation) вместо прямого присваивания значений этому свойству, чтобы управлять автоматическим возвратом в центр с помощью параметра `force`.
:::

### `arrowLineWidth` <decl type="number" get set />

Ширина линии навигационного маршрута в пикселях, значение по умолчанию — `12`.

### `arrowLineBackgroundColor` <decl type="color" get set />

**Цвет фона** навигационного маршрута (цвет уже пройденного участка). Принимает значения цветов CSS, по умолчанию `#898b90`.

### `arrowLineForgeColor` <decl type="color" get set />

**Цвет переднего плана** навигационного маршрута (цвет оставшейся части маршрута). Принимает значения цветов CSS, по умолчанию `#4b73ec`.

### `smallMem` <decl type="boolean" get set />

Включать ли режим работы на устройствах с ограниченным объемом памяти (Low Memory), по умолчанию `false`.

При включении `mapview` объединяет и масштабирует четыре тайла размером 256×256 в одно изображение 512×512 для рендеринга. Это снижает количество одновременно кэшируемых в памяти тайлов для адаптации под устройства с ограниченной оперативной памятью.

::: warning
Режим экономии памяти ухудшает детализацию карты, поэтому его следует включать только при явной нехватке памяти на устройстве.
:::

### `missTiles` <decl type="Array<{ z: number, x: number, y: number }>" get listen />

Свойство только для чтения, срабатывает, когда карта обнаруживает отсутствие локальных файлов тайлов. Параметр обратного вызова представляет собой массив, каждый элемент которого описывает один недостающий тайл:

| Поле | Тип | Описание |
| :-- | :-- | :-- |
| `z` | `number` | Уровень масштабирования (Zoom Level) |
| `x` | `number` | Координата X тайла (номер столбца) |
| `y` | `number` | Координата Y тайла (номер строки) |

Получив это событие, приложение обычно должно скачать соответствующие файлы тайлов с сервера и после завершения загрузки вызвать [`reload()`](#reload) для обновления карты:

```js
export default {
  missTileHandler(tiles) {
    // tiles: [{ z: 17, x: 105234, y: 49832 }, ...]
    downloadTiles(tiles).then(() => {
      this.$element('mapview').reload()
    })
  }
}
```

```html
<mapview id="mapview" on:missTiles="missTileHandler" />
```

### `directionInfo` <decl type="{ event: string, stepIndex?: number, distance?: number }" get listen />

Свойство событий карты только для чтения, срабатывает при выполнении следующих действий с картой:

| Значение `event` | Момент срабатывания | Дополнительные поля |
| :-- | :-- | :-- |
| `"move"` | Срабатывает при панорамировании карты пользователем с помощью жестов | Нет |
| `"calc"` | Срабатывает при пересчете местоположения и отклонения от маршрута во время навигации | `stepIndex` (индекс текущего участка маршрута), `distance` (расстояние отклонения текущего положения от маршрута в метрах) |

```js
export default {
  onDirectionInfo(info) {
    if (info.event === 'move') {
      // Пользователь вручную перетащил карту, можно приостановить автоматическое центрирование
    } else if (info.event === 'calc') {
      console.log(`Текущий шаг: ${info.stepIndex}, расстояние отклонения: ${info.distance} м`)
    }
  }
}
```

## Методы

### `reload()`

Перезагружает все тайлы. Этот метод необходимо вызывать для обновления отображения карты после записи новых файлов тайлов в локальное хранилище.

```js
this.$element('mapview').reload()
```

### `locate()`

Перемещает центр карты в текущее местоположение (координаты, заданные в [`navCoordinate`](#navcoordinate)). Используется для функции «вернуться к текущему местоположению».

```js
this.$element('mapview').locate()
```

### `setLocation(location)`

Устанавливает координаты текущего местоположения и опционально перемещает центр карты в эту точку.

| Поле параметра | Тип | Описание |
| :-- | :-- | :-- |
| `latitude` | `number` | Широта |
| `longitude` | `number` | Долгота |
| `force` | `boolean` | Если `true`, немедленно центрирует карту на этих координатах (эквивалентно вызову [`locate()`](#locate)); если `false`, обновляет только положение значка |

```js
// Обновляем только положение значка, не перемещая карту
this.$element('mapview').setLocation({
  latitude: 39.9042,
  longitude: 116.4074,
  force: false,
})

// Обновляем положение значка и центрируем карту на этих координатах
this.$element('mapview'].setLocation({
  latitude: 39.9042,
  longitude: 116.4074,
  force: true,
})
```

### `startNav(linePoints)`

Устанавливает навигационный маршрут и запускает навигацию. После вызова карта автоматически позиционируется на начале маршрута и прорисовывает его целиком.

`linePoints` — массив точек маршрута, где каждый элемент представляет собой двумерный массив в формате `[долгота, широта]`:

```js
const route = [
  [116.397428, 39.909736],  // [долгота, широта]
  [116.404730, 39.913370],
  [116.410072, 39.918933],
]
this.$element('mapview').startNav(route)
```

::: warning
Внимание к порядку параметров: первым значением для каждой координатной точки является **долгота** (longitude), а вторым — **широта** (latitude), что противоположно общепринятому соглашению «широта на первом месте».
:::

### `insetNavPoint(linePoints)`

Добавляет точки маршрута к существующему навигационному маршруту. Формат аналогичен [`startNav()`](#startnav). Применяется в сценариях поэтапного получения данных маршрута. После добавления необходимо вызвать [`reload()`](#reload) для обновления отображения.

```js
this.$element('mapview').insetNavPoint(newPoints)
this.$element('mapview').reload()
```

## Примеры использования

### Базовое отображение карты

В следующем примере показано, как настроить базовый компонент карты, прослушивать событие отсутствия тайлов и инициировать их скачивание.

```html
<template>
  <mapview
    id="map"
    :zoomLevel="zoom"
    :baseUri="tileBaseUri"
    :tileType="tileType"
    loadPlace="/assets/imgs/tile-loading.png"
    arrowIcon="/assets/imgs/location.png"
    on:missTiles="onMissTiles"
    on:directionInfo="onDirectionInfo"
  />
</template>
```

```js
export default {
  data: {
    zoom: 17,
    tileType: 0,
    tileBaseUri: 'internal://files/tiles/my_provider',
  },

  onReady() {
    // Инициализация текущего местоположения
    this.$element('map').setLocation({
      latitude: 39.9042,
      longitude: 116.4074,
      force: true,
    })
  },

  onMissTiles(tiles) {
    // tiles: список отсутствующих тайлов, отправка запроса на загрузку с сервера
    fetchTilesFromServer(tiles).then(() => {
      this.$element('map').reload()
    })
  },

  onDirectionInfo(info) {
    if (info.event === 'move') {
      // Пользователь выполнил панорамирование карты
    }
  },
}
```

```css
mapview {
  width: 100%;
  height: 100%;
}
```

### Прорисовка навигационного маршрута

```html
<template>
  <stack>
    <mapview
      id="map"
      :baseUri="tileBaseUri"
      :zoomLevel="zoom"
      arrowIcon="/assets/imgs/location.png"
      arrowLineWidth="10"
      arrowLineBackgroundColor="#888888"
      arrowLineForgeColor="#1a73e8"
      on:missTiles="onMissTiles"
    />
    <button @click="startNavigation">Начать навигацию</button>
  </stack>
</template>
```

```js
export default {
  data: {
    zoom: 16,
    tileBaseUri: 'internal://files/tiles/my_provider',
  },

  startNavigation() {
    const route = [
      [116.397428, 39.909736],
      [116.404730, 39.913370],
      [116.410072, 39.918933],
    ]
    this.$element('map').startNav(route)
  },

  onMissTiles(tiles) {
    fetchTilesFromServer(tiles).then(() => {
      this.$element('map').reload()
    })
  },
}
```

### Адаптация для устройств с малым объемом памяти

```html
<mapview
  id="map"
  :baseUri="tileBaseUri"
  :zoomLevel="zoom"
  :smallMem="isLowEndDevice"
/>
```

```js
import SysDevice from '@system.device'

export default {
  data: {
    zoom: 17,
    tileBaseUri: 'internal://files/tiles/my_provider',
    isLowEndDevice: false,
  },
  onInit() {
    // Определение необходимости включения режима экономии памяти на основе объема ОЗУ устройства
    this.isLowEndDevice = SysDevice.memoryProfile <= 4096
  },
}
```
