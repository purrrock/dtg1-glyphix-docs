# slider-arc

Дуговой ползунок выбора, по умолчанию является блочным элементом, изменение стилей в настоящее время не поддерживается.

## Свойства

Наследует свойства компонента [slider](slider).

### `arc-center` <decl type="{ x: number, y: number }" set />

Устанавливает положение центра дуги.

### `start-angle` <decl type="number" set />

Устанавливает начальный угол дуги, значение по умолчанию: $-90$.

### `progress-angle` <decl type="number" set />

Устанавливает максимальный угол поворота дуги, значение по умолчанию: $360$ (полный круг).

### `arc-width` <decl type="number" set />

Устанавливает ширину дуги.

### `arc-radius` <decl type="number" set />

Устанавливает радиус дуги.
