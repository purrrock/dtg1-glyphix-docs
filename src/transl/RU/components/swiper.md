# swiper

Контейнер представлений карточек (карусель/свайпер), поддерживающий любые дочерние компоненты. Направление прокрутки представления карточек определяется конкретным способом компоновки: список с компоновкой `flex-column` является вертикальным, а список с компоновкой `flex-row` — горизонтальным.

## Свойства

### `scroll` <decl type="{ scrollX: number, scrollY: number, scrollState: number }" get listen />

Значение свойства `scroll` представляет собой объект, содержащий следующие поля: `scrollX`, `scrollY` и `scrollState`. Свойства `scrollX` и `scrollY` обозначают положение прокрутки по горизонтали и вертикали соответственно, в пикселях; свойство `scrollState` обозначает состояние прокрутки и может принимать значение $0$, $1$ или $2$, значения которых приведены в таблице ниже. С помощью директивы `on` можно прослушивать изменения свойства `scroll`. Любое изменение позиции контента, вызванное действиями пользователя или API, запускает прослушивание.

| Значение `scrollState` | Описание эффекта                                                                                    |
| :--------------------: | --------------------------------------------------------------------------------------------------- |
|          $0$           | Прокрутка остановлена                                                                               |
|          $1$           | Выполняется прокрутка жестом пользователя                                                           |
|          $2$           | Пользователь отпустил палец, прокрутка вызвана методами вроде [`scrollTo`](#scrollto) или инерцией    |

### `scrollTop` <decl type="number" get listen />

Положение прокрутки по вертикали, то есть расстояние от верхней границы контента компонента `swiper` до верхней границы области просмотра, в пикселях. С помощью этого свойства можно отслеживать изменения положения прокрутки. В отличие от свойства [`scroll`](#scroll), прослушивание самого свойства `scrollTop` не позволяет определить, была ли прокрутка вызвана жестом пользователя, вызовом API или инерцией.

### `scrollLeft` <decl type="number" get listen />

Положение прокрутки по горизонтали, то есть расстояние от левой границы контента компонента `swiper` до левой границы области просмотра, в пикселях. С помощью этого свойства можно отслеживать изменения положения прокрутки. В отличие от свойства [`scroll`](#scroll), прослушивание самого свойства `scrollLeft` не позволяет определить, была ли прокрутка вызвана жестом пользователя, вызовом API или инерцией.

### `scrollWidth` <decl type="number" get listen />

Ширина области контента компонента `swiper`. Ширина `swiper` при вертикальной компоновке равна ширине области просмотра, а при горизонтальной компоновке равна сумме ширин всех элементов. С его помощью можно отслеживать изменения ширины контента.

### `scrollHeight` <decl type="number" get listen />

Высота области контента компонента `swiper`. Высота `swiper` при вертикальной компоновке равна высоте области просмотра, а при горизонтальной компоновке равна сумме высот всех элементов. С его помощью можно отслеживать изменения высоты контента.

### `snapshot` <decl type="boolean" get set />

Когда свойство `snapshot` включено, дочерние компоненты `swiper` переходят в режим снимка (snapshot). Пожалуйста, обратитесь к свойству [`snapshot`](scroll.md#snapshot) компонента `scroll`.

### `deformation` <decl type="string" set />

Задает эффект деформации дочерних элементов, с помощью которого можно реализовать такие внешние виды, как "рыбий глаз" (fisheye). Вы можете указать встроенный эффект деформации по имени (строке) либо определить его с помощью функции JavaScript.

| Значение | Описание эффекта |
| :---: | :--- |
| `'none'` | Без эффекта деформации (значение по умолчанию). |
| `'fade'` | Эффект затухания и масштабирования при переключении. Этот эффект подчеркивает «фокус» на элементах внутри текущей области просмотра и делает элементы за ее пределами менее заметными. Подробности см. в примере в этом разделе. |
| `'fisheye'` | Встроенный эффект «рыбий глаз». Этот компонент свойств используется для компонента [`scroll`](scroll.md), а не `swiper`. |
| function | Определение эффекта деформации с помощью функции JavaScript. |

Эффект деформации должен быть константным и не должен изменяться.

Если содержимое дочерних элементов `swiper` часто меняется, при использовании эффекта деформации рекомендуется добавить к элементам свойство [`quiescent`](/framework/generic/properties.md#quiescent), чтобы избежать обновления при переключении и повысить производительность. Вы можете обратиться к следующему примеру:

<glyphix id="components-swiper-deformation" height="360" width="360" title="Эффект деформации элементов">

```html
<swiper deformation="fade" indicator>
  <div for="x in 5" :quiescent="x != 0">
    <progress-arc busy :start-angle="0" :stop-angle="360" />
    <p>pane {{ x + 1 }}</p>
  </div>
</swiper>
```

``` css
div {
  background-color: #eee;
  text-align: center;
  margin: 10px;
  border-radius: 24px;
  display: flex;
  flex-direction: column;
  justify-content: center;
}

progress-arc {
  width: 30%;
  height: 30%;
  margin-bottom: 5%;
}
```

</glyphix>

Первый дочерний элемент в примере не имеет включенного свойства `quiescent`, поэтому он будет непрерывно обновляться в процессе переключения, в то время как остальные элементы прекратят обновление.

### `vertical` <decl type="boolean" set />

Задает вертикальную компоновку компонента `swiper`. По умолчанию установлено значение `false`, при котором используется горизонтальная компоновка. Следующий пример демонстрирует интерактивный эффект `swiper` при вертикальной компоновке (обратите внимание, что прокрутка должна быть вертикальной, горизонтальные свайпы не вызывают реакции).

<glyphix id="components-swiper-vertical" height="360" width="360" title="Вертикальная компоновка">

``` html
<swiper vertical deformation="fade" indicator>
  <p for="x in 5">
    pane {{ x + 1 }}
    {{ x == 0 ? '(swipe up)' : x == 4 ? '(swipe down)' : '' }}
  </p>
</swiper>
```

``` css
p {
  background-color: #eee;
  text-align: center;
  margin: 10px;
  border-radius: 24px;
}
```

</glyphix>

### `indicator` <decl type="boolean" get set />

Определяет, отображать ли точечный индикатор (индикатор страниц) у компонента `swiper`. Позиция отображения точечного индикатора определяется свойством `vertical`: при вертикальной компоновке точечный индикатор отображается по центру справа, а при горизонтальной — по центру внизу. Подробный эффект см. в примерах свойств [`deformation`](#deformation) и [`vertical`](#vertical).

Обратитесь к разделу [CSS-свойства точечного индикатора](#css-свойства-точечного-индикатора), чтобы узнать, как настроить стиль отображения точечного индикатора.

### `pageLength`  <decl type="number" set />

Задает размер или долю дочерней страницы. Если указано в процентах, задает размер дочернего компонента в направлении прокрутки (относительно самого компонента); если указано другое число, задает размер дочернего компонента в направлении прокрутки в пикселях.

### `index`  <decl type="number" get set listen />

Индекс текущего отображаемого дочернего компонента. При установке свойства `index` компонент с помощью анимации прокрутится к указанному дочернему компоненту. Вы можете прослушивать изменения положения с помощью директивы `on`, а при изменении индекса дочернего компонента его можно отследить через свойство `index`.

### `finalChanged` <decl type="bool" get set />

Задает, следует ли вызывать событие изменения [`index`](#index) только после остановки прокрутки. По умолчанию (то есть когда `finalChanged` имеет значение `false`), событие прослушивания срабатывает всякий раз, когда жест прокрутки или другая причина изменяет свойство `index` компонента `swiper`. Однако это может легко привести к пропуску кадров анимации или слишком частым, ненужным вызовам событий. Если установлено свойство `finalChanged`, событие изменения `index` будет срабатывать только тогда, когда прокрутка полностью остановится.

::: tip
При реализации эффектов вроде точечных индикаторов путем прослушивания свойства `index` рекомендуется устанавливать `finalChanged` в значение `true`, так как это позволяет избежать пропуска кадров, вызванного обновлениями рендеринга из-за срабатывания событий в процессе свайпа.
:::

### `weakGesture` <decl type="'none' | 'start' | 'end' | 'edge'" get set />

Задает ситуации, в которых компонент `swiper` будет распространять (всплытие) жесты прокрутки. По умолчанию `swiper` предотвращает всплытие обрабатываемых им жестов, поэтому его родительский элемент не может получить жест, заставляющий `swiper` прокручиваться. `weakGesture` позволяет включить всплытие событий жестов при перетаскивании до границ содержимого, позволяя родительскому элементу принимать эти жесты.

| Значение  | Описание                                                                        |
| :-------: | ------------------------------------------------------------------------------- |
| `'none'`  | Не передавать (не всплывать) события жестов.                                    |
| `'start'` | Передавать события жестов после перетаскивания к начальной позиции контента.    |
|  `'end'`  | Передавать события жестов после перетаскивания к конечной позиции контента.     |
| `'edge'`  | Передавать события жестов после перетаскивания к начальной или конечной позиции контента. |

Если базовый элемент страницы представляет собой горизонтальный компонент `swiper`, но вы хотите, чтобы жест свайпа вправо возвращал назад (на предыдущую страницу), вы можете настроить его следующим образом:
``` html
<swiper weak-gesture="start"> ... </swiper>
```
Когда пользователь прокрутит до начала компонента `swiper` и продолжит свайп вправо, он сможет выйти со страницы.

### `bounces` <decl type="'none' | 'start' | 'end' | 'edge'" get set />

Задает, следует ли запускать отскок (bounce) после прокрутки `swiper` к границе с помощью жеста. Начальное значение этого свойства — `edge`, что означает разрешение отскока как в начальной, так и в конечной точках. Свойство `bounces` компонента `swiper` похоже на свойство [`bounces`](scroll.md#bounces) компонента [`scroll`](scroll.md), подробнее см. в соответствующей документации.

### `scrolled` <decl type="boolean" listen />

С помощью свойства `scrolled` можно отслеживать, находится ли компонент `swiper` в состоянии прокрутки. Значение свойства `true` указывает на то, что выполняется прокрутка, в противном случае это означает, что прокрутка остановлена.

Как операции прокрутки, вызванные касанием пользователя, так и программная прокрутка через свойство `scroll` вызывают событие `scrolled`. При выходе из состояния прокрутки значение параметра события `scrolled` равно `false`.

### `setIndex`
<decl method><pre>
(options: {
  index: number,
  behavior?: 'instant' | 'smooth'
}): void
</pre></decl>

Перемещает область просмотра к дочернему компоненту, указанному по индексу. Если это перемещение выходит за пределы границ области просмотра, положение области просмотра остановится на первом или последнем компоненте. Назначение свойств объекта `options`:
- `index`: индекс целевого дочернего компонента для перемещения, $0$ обозначает первый дочерний компонент.
- `behavior`: если указано `'smooth'`, используется плавный переход с анимацией; если `'instant'` (значение по умолчанию), происходит мгновенное перемещение в позицию указанного дочернего компонента.

### `scrollTo` <decl type="(position: number): void" method />

Прокручивает содержимое в указанную позицию, направление прокрутки совпадает с направлением компоновки компонента scroll.

Метод `scrollTo` игнорирует эффект привязки (snap) элементов.

## Спецификация CSS

### CSS-свойства точечного индикатора

В этом разделе описываются CSS-свойства, доступные для компонента `swiper` при включении свойства [`indicator`](#indicator), которые используются для управления некоторыми аспектами внешнего вида точечного индикатора. Точечный индикатор `swiper` всегда отображается в виде группы горизонтально или вертикально расположенных точек, и разработчики могут настраивать их стиль только на этой основе.

#### `indicator-color`

Определяет цвет невыбранных точек индикатора. Эффект выглядит следующим образом:

<glyphix id="components-swiper-indicator-color" height="360" width="360" title="Цвет точечного индикатора">

```html
<swiper indicator>
  <div for="x in 5">
    <p>pane {{ x + 1 }}</p>
  </div>
</swiper>
```

``` css
div {
  background-color: #eee;
  text-align: center;
  margin: 10px;
  border-radius: 24px;
  display: flex;
  flex-direction: column;
  justify-content: center;
}

swiper {
  indicator-color: #333;
  indicator-selected-color: #ff60ff;
  indicator-bottom: 16px;
}
```

</glyphix>

#### `indicator-selected-color`

Определяет цвет выбранной точки индикатора. Эффект можно посмотреть в примере для свойства [`indicator-color`](#indicator-color), где можно заметить, что точка индикатора, соответствующая выбранной странице, отображается цветом, заданным этим CSS-свойством.

#### `indicator-size`

Определяет размер каждой точки в точечном индикаторе в пикселях. Значение по умолчанию — `10px`. Следующий пример демонстрирует эффект установки размера точечного индикатора на `16px`:

<glyphix id="components-swiper-indicator-size" height="360" width="360" title="Размер точечного индикатора">

```html
<swiper indicator>
  <div for="x in 5">
    <p>pane {{ x + 1 }}</p>
  </div>
</swiper>
```

``` css
div {
  background-color: #eee;
  text-align: center;
  margin: 10px;
  border-radius: 24px;
  display: flex;
  flex-direction: column;
  justify-content: center;
}

swiper {
  indicator-color: #333;
  indicator-selected-color: #ff60ff;
  indicator-bottom: 24px;
  indicator-size: 16px;
}
```

</glyphix>

#### `indicator-top`

Когда `swiper` имеет [горизонтальную компоновку](#vertical), с помощью свойства `indicator-top` можно задать расстояние от точечного индикатора до верхнего края. По умолчанию точечный индикатор отображается по центру внизу, а это свойство позволяет разместить его сверху:

<glyphix id="components-swiper-indicator-top" height="360" width="360" title="Верхний точечный индикатор">

```html
<swiper indicator>
  <div for="x in 5">
    <p>pane {{ x + 1 }}</p>
  </div>
</swiper>
```

``` css
div {
  background-color: #eee;
  text-align: center;
  margin: 10px;
  border-radius: 24px;
  display: flex;
  flex-direction: column;
  justify-content: center;
}

swiper {
  indicator-top: 16px;
}
```

</glyphix>

::: warning
Не устанавливайте одновременно `indicator-left`, `indicator-top`, `indicator-right` и `indicator-bottom`, так как это приведет к непредвиденному положению точечного индикатора.
:::

#### `indicator-left`

Когда `swiper` имеет [вертикальную компоновку](#vertical), с помощью свойства `indicator-left` можно задать расстояние от точечного индикатора до левого края. По умолчанию точечный индикатор отображается по центру справа, а это свойство позволяет разместить его слева:

</glyphix>

  margin: 10px;

#### `indicator-bottom`

Когда `swiper` имеет [горизонтальную компоновку](#vertical), с помощью свойства `indicator-bottom` можно задать расстояние от точечного индикатора до нижнего края. Эффект можно посмотреть в примерах свойств [`indicator-color`](#indicator-color) и [`indicator-size`](#indicator-size).

### `padding` и `overflow` <version-badge since="0.9" />

См. соответствующие пояснения в [компоненте scroll](scroll.md#padding-和-overflow). Свойства `padding` и `overflow` компонента `swiper` имеют такие же правила поведения, как и одноименные свойства компонента `scroll`. Дополнительные сведения см. в связанной документации.
