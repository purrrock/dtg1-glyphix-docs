# Часто задаваемые вопросы

## Инструменты сборки

### Проблемы сборки проекта

#### Ошибка `Lisp Error: thread killed`

Обычно это проявляется в виде следующего сообщения об ошибке:

``` log
[ 47%] Process image src/assets/images/frame1.png
error: Lisp Error: thread killed
```

Эта проблема возникает из-за ошибки на одном из предыдущих шагов сборки, в результате чего текущая операция конвертации изображений была отменена. Для решения достаточно исправить операцию сборки, вызвавшую критическую ошибку (`fatal`), никаких других специальных действий предпринимать не требуется.

### Эмулятор

#### Язык эмулятора по умолчанию

Языком эмулятора по умолчанию является `zh-CN`. Поэтому, если вы добавили конфигурацию [интернационализации](/framework/component/i18n.md), по умолчанию будет использоваться файл перевода `zh-CN.json`. При запуске эмулятора с помощью команды `gx` можно использовать параметры `-l` или `--language` для указания языка:
``` shell
gx emu -l en-US # Использовать американский английский
```
Вы также можете динамически изменять язык во время работы эмулятора с помощью инструмента отладки inspector.
