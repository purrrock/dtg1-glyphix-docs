# Часто задаваемые вопросы

## Инструменты сборки

### Проблемы сборки проекта

#### Ошибка `Lisp Error: thread killed`

Конкретным проявлением является появление сообщения об ошибке, похожего на следующее:

``` log
[ 47%] Process image src/assets/images/frame1.png
error: Lisp Error: thread killed
```

Эта проблема возникает из-за ошибки в одной из предыдущих задач сборки, что приводит к отмене выполняющейся в данный момент операции конвертации изображений. Для восстановления достаточно исправить ошибку сборки уровня `fatal`, никаких специальных действий предпринимать не требуется.

### Эмулятор

#### Язык эмулятора по умолчанию

Язык эмулятора по умолчанию — `zh-CN`. Поэтому, если вы добавили конфигурацию [интернационализации](/framework/component/i18n.md), по умолчанию будет использоваться файл переводов `zh-CN.json`. При запуске эмулятора с помощью команды `gx` вы можете использовать опцию `-l` или `--language` для указания языка:
``` shell
gx emu -l en-US # Использовать американский английский
```
Вы также можете динамически менять язык во время работы эмулятора с помощью инструмента отладки inspector.
