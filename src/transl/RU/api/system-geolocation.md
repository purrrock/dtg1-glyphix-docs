# Геолокация

## Импорт модуля

```js
import geolocation from '@system.geolocation';
```

Разработчикам необходимо заявить о доступе приложения к权限 `watch.permission.LOCATION` в файле [`manifest.json`](/framework/application/manifest.md#permissions).

## Определение интерфейсов

### `getLocation` 
<decl method><pre>
(options: {
  mode?: string
  timeout?: number
}): Promise&lt;Location>
</pre></decl>

Однократно получает текущие широту и долготу местоположения, возвращая асинхронную [информацию о местоположении](#location).

Описание параметров `options`
- `mode` : Указывает точность определения местоположения: `fine` — точное определение, `coarse` — приблизительное. Значение по умолчанию — `coarse`.
- `timeout` : Тайм-аут определения местоположения в миллисекундах (`ms`), по умолчанию равен 30000.

### `subscribe` <decl type="(callback: (location: Location) => void): number" method/>

Подписка на изменение местоположения. Параметр `callback` принимает `location`, являющийся текущей [информацией о местоположении](#location). Возвращаемый этим методом ID может быть использован в методе [`unsubscribe()`](#unsubscribe) для отмены подписки.

### `unsubscribe` <decl type="(subscribeID: number): void" method/>

Отмена подписки на изменение местоположения.

## Определение типов

### `Location`

Используется для представления данных о геолокации.

```ts
type Location = {
  code: number; // Код состояния геолокации, указывающий, действительна ли текущая информация о местоположении
  msg: string; // Сообщение об ошибке геолокации
  data: {
    // Данные о местоположении
    longitude: number; // Значение долготы (Примечание: в китайском оригинале ошибочно подписано как 纬度 — широта, сохранено семантическое назначение)
    latitude: number; // Значение широты
    coordType: string; // Тип системы координат, например 'WGS84', 'GCJ02' и т.д.
  };
};
```

Коды состояния геолокации для поля `code`:

- `200`: Текущая информация о местоположении действительна;
- `1002`: Телефон в данный момент не подключен к сети Bluetooth
- `1300`: Телефон не может получить службы геолокации
- `1301`: На телефоне не включены службы геолокации
- `1302`: Приложению на телефоне не предоставлено разрешение на геолокацию
- `1399`: Неизвестная ошибка
