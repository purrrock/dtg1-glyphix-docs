# Меню с размытым оверлеем

## Демонстрация эффекта

В этом руководстве показана техника разработки меню с перекрывающим слоем после размытия фона. В следующем примере продемонстрирован такой интерактивный эффект (нажмите на кнопку «...» в правом нижнем углу, чтобы показать интерфейс перекрытия).

Основная цель этого руководства — показать, как реализовать интерфейс с размытием с помощью Glyphix.

## Метод реализации

### Тень текста

Тень текста «Hokkaido sika deer» в примере может быть реализована путем наложения слоя размытого текста:
``` html
<stack class="wallpaper-title">
  <p class="shadow">Hokkaido sika deer</p>
  <p>Hokkaido sika deer</p>
</stack>
```
Поместите два одинаковых текста в компонент [`stack`](/components/stack.md) и используйте нижний текст в качестве тени. Это достигается с помощью CSS-класса `shadow` для нижнего текста:
``` css
.shadow {
  color: #0008;
  /* Добавляем размытие фонового текста для создания эффекта тени */
  filter: blur(8px);
  /* Необходимо использовать transparent, чтобы пометить элемент как прозрачный */
  transparent: true;
}
```
Установите цвет фонового текста полупрозрачным серым и примените компонент текста `<p>` в качестве тени с помощью свойства фильтра размытия ([`filter: blur(8px)`](/framework/generic/styles.md#filter)). Обратите внимание, что цвет текста на переднем плане не должен быть прозрачным, иначе он может наложиться на слой `.shadow`.

### Пользовательский шрифт

Текст «Hokkaido sika deer» отображается с использованием пользовательского шрифта. В Glyphix вы можете импортировать пользовательские шрифты тем же способом, что и в веб-разработке:
``` css
@font-face {
  font-family: 'Playwrite Australia SA';
  src: url('/assets/PlaywriteAUSA-Regular.ttf');
}

.wallpaper-title {
  font-family: 'Playwrite Australia SA', 'sans-serif';
  color: #ffffff;
  margin-top: 25%;
}
```
Как видите, вы можете объявить шрифт в CSS с помощью блока [`@font-face`](/framework/generic/styles.md#font-face-规则) и ссылаться на него в свойстве элемента [`font-family`](/framework/generic/styles.md#font-family).

### Размытие фонового слоя

Поскольку страницы, вызываемые в настоящее время через [`router` API](/api/system-router.md), не поддерживают полупрозрачный фон, вы не можете использовать страницы для реализации всплывающего меню. Однако вы можете использовать этот прием для симуляции всплывающей «страницы»:
``` html
<stack class="window" :disabled="popups">
  <image class="wallpaper" src="/assets/images/sika-deer.jpg" />
  ...
</stack>
<div class="overlay" if="popups">
  ...
</div>
```
Вам нужно добавить в страницу два слоя элементов (в этом примере `stack.window` и `div.overlay`) и управлять ими с помощью условия (например, `popups`). В частности:
- `popups` управляет свойством `disabled` фонового элемента, поэтому, когда `popups` имеет значение true, фоновый элемент не будет реагировать на ввод жестов и т. д.;
- `popups` также управляет рендерингом верхнего слоя. Когда он имеет значение true, верхний элемент отображается.

Когда слой перекрытия появляется, свойство [`disabled`](/framework/generic/properties.md#disabled) также предоставляет возможность размыть фоновый элемент:
``` css
.window:disabled {
  filter: blur(40px);
}
```
Когда для элемента установлено свойство `disabled`, также активируется псевдокласс `:disabled` фонового элемента, поэтому эффект размытия в CSS выше начнет работать.

::: tip
Поскольку Glyphix не поддерживает браузерное свойство [`backdrop-filter`](https://developer.mozilla.org/docs/Web/CSS/backdrop-filter), вы не можете напрямую применять правила CSS для `div.overlay` для достижения размытия фона, а должны использовать технику из этого примера.
:::

## Риски для производительности

Поскольку эффект размытия является ресурсоемким процессом, разработчикам следует уделять особое внимание нагрузке на производительность. Мы рекомендуем использовать эффекты размытия только в статических интерфейсах и, желательно, добавлять свойство [`quiescent`](/framework/generic/properties.md#quiescent) к размываемым элементам.

Если возможно, протестируйте интерфейс с размытием на физическом устройстве, чтобы убедиться, что он соответствует ожиданиям по производительности.
