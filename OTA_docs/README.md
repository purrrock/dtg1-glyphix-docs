# ATS3085S Firmware Packer / Unpacker

Набор утилит на Python для реверс-инжиниринга, распаковки, модификации и обратной сборки OTA-прошивок смарт-часов на базе аппаратной платформы **Actions Semiconductor ATS3085S** (ОС Glyphix / Zephyr RTOS), таких как **DT NO.1 G1** и аналогичные.

Этот инструментарий позволяет преодолеть проприетарную структуру "матрешки" `AOTA`-контейнеров, извлекать системные ресурсы (VFS) и ядро (`app.bin`), вносить патчи и генерировать 100% валидный OTA-образ для прошивки по Bluetooth (BLE).

---

## ⚠️ Отказ от ответственности
**Инструмент предназначен исключительно для исследовательских и образовательных целей.** Некорректная модификация ядра ОС, системных флагов или таблицы векторов прерываний (IVT) может привести к "окирпичиванию" (hard-brick) вашего устройства. Используйте на свой страх и риск.

---

## Особенности архитектуры

Обновления для платформы ATS3085S поставляются в виде нешифрованных контейнеров. Защита целостности строится исключительно на каскаде контрольных сумм **CRC32 (zlib)**.

Прошивка представляет собой трехуровневую матрешку:
* **Layer 1 (Внешний AOTA):** Главный контейнер (`.bin`), содержащий метаданные `ota.xml`, ресурсы интерфейса (`sdfs_a.bin`, `sdfs_k.bin`) и образ загрузчика.
* **Layer 2 (Загрузчик TEMP.bin):** Бинарный файл, состоящий из загрузочного заголовка (`ACTHHTCA`), аппаратного Boot Stub и непрерывного потока XZ-сжатых чанков (по 2 MiB).
* **Layer 3 (Внутренний AOTA):** Монолитный образ, получаемый после декомпрессии всех XZ-чанков. Содержит исполняемое ядро `app.bin` (Zephyr + Glyphix) и системные конфиги.

> Подробная техническая информация о форматах и алгоритмах доступна в каталоге `docs/`.

## Структура репозитория

* `aota_full_unpack.py` — Главный пайплайн для полной рекурсивной распаковки прошивки до слоя ядра.
* `aota_full_pack.py` — Главный пайплайн для обратной каскадной сборки модифицированных файлов в готовый OTA-образ.
* `BT_ota_flasher.py` — Скрипт для прошивки собранного `.bin` файла в часы по Bluetooth Low Energy (BLE). Пока что не работает, в процессе отладки.
* `tools/` — Низкоуровневые утилиты для ручной отладки каждого слоя (распаковщики FAT, декомпрессоры XZ).
* `docs/` — Инженерная документация по реверс-инжинирингу.

## Инструкция по использованию

### Требования
* Python 3.8+
* Отсутствие сторонних зависимостей для сборки (используются только стандартные библиотеки `struct`, `lzma`, `zlib`).

### 1. Распаковка оригинальной прошивки
Скормите оригинальный файл обновления (как скачать заводкую ОТА прошивку описано в How-to_flashing.md) главному распаковщику:

```bash
python aota_full_unpack.py original_firmware.bin
```

Скрипт создаст структуру каталогов:
```text
original_firmware_extracted/                  <-- Layer 1
├── ota.xml
├── version.txt
├── sdfs_a.bin
├── sdfs_k.bin
└── TEMP_extracted/                           <-- Layer 2
    ├── actions_boot_header.bin
    ├── boot_stub.bin
    └── inner_aota_extracted/                 <-- Layer 3 (Целевая папка для моддинга)
        ├── ota.xml
        ├── app.bin                           <-- Исполняемое ядро (ARM Thumb-2)
        └── sdfs.bin
```

### 2. Модификация (Modding)
Вы можете редактировать файлы файловой системы или дизассемблировать `app.bin` (Ghidra / IDA Pro), вносить ARM Thumb-2 патчи и сохранять app.bin обратно в директорию `inner_aota_extracted/`.

*Примечание: Если вы хотите изменить версию прошивки, чтобы часы приняли даунгрейд или кастом, отредактируйте значение `build_ver` в файле `version.txt` (в корне `original_firmware_extracted/`). Утилита сборки автоматически пропатчит все `ota.xml`.*

### 3. Сборка модифицированной прошивки
Укажите корневой каталог извлеченной прошивки и имя выходного файла:

```bash
python aota_full_pack.py original_firmware_extracted/ custom_firmware.bin
```

Скрипт автоматически:
1. Выровняет размеры `app.bin` по 512-байтовым секторам.
2. Соберет монолит Layer 3.
3. Нарежет монолит на 2 MiB блоки и сожмет их в формат XZ.
4. Приклеит Boot Stub и соберет валидный `TEMP.bin` (Layer 2).
5. Обновит все размеры и CRC32 внутри `ota.xml`.
6. Сгенерирует финальный AOTA-контейнер (Layer 1).

### 4. Прошивка устройства
Инструкция по загрузке готового `custom_firmware.bin` в часы находится в файле [How-to_flashing.md](How-to_flashing.md).
